# Sprint 1 – Authentication & Foundation

## Duration

Week 1–2

## Goal

Allow users to register and login into the system.

## User Stories

### US-01 Register

As a Guest, I want to create an account so that I can purchase products.

### Tasks

- Register page
- Form validation
- API integration
- Error handling

### US-02 Login

As a Customer, I want to login so that I can access protected features.

### Tasks

- Login page
- JWT authentication
- Route guards
- Session management

### US-03 Layout Foundation

- Header
- Footer
- Navigation menu
- Responsive layout

## Deliverables

- Home Page
- Login Page
- Register Page
- Authentication Module

## Milestone Sprint 1

✅ User registration completed

✅ User login completed

✅ JWT authentication working

✅ Route protection implemented

✅ Responsive layout completed

# Definition of Done (DoD)

A User Story is considered complete when:

- Code is committed to Git repository
- Code review completed
- Project builds successfully
- No critical defects
- Responsive on desktop, tablet, and mobile
- Loading and error states handled
- Manual testing completed
- Mentor approval received
